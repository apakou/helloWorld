# Hello World

An open-source project for programming beginners. Explore and contribute a simple `Hello World` example in your favorite programming language.

The language catalog and contributor roster are starting fresh. New examples are welcome; see [CONTRIBUTING.md](CONTRIBUTING.md) for the sample format and pull request steps. Please also read the [Code of Conduct](CODE_OF_CONDUCT.md).

See the restarted [contributors list](CONTRIBUTORS.md) to be recognized for a merged contribution.

## Run locally

Open `index.html` in a browser, or start a local server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Project files

- `index.html`, `styles.css`, and `script.js` power the website.
- `source/basic/` is where language examples will live.
- `CONTRIBUTING.md` explains how to add an example.
- `.github/ISSUE_TEMPLATE/` helps propose a new example.
